# ProblyStolen_friendwine
本项目是深空当铺：可能是偷的   相关mod：朋友的酒

项目描述：使用本mod会使部分顾客NPC像邦友的酒那样上下Q弹跳动

项目使用方法：下载ProblyStolen_friendwine.dll文件，将其放入深空当铺游戏根目录下的Mods文件夹内。

注意：本Mod依赖于MelonLoader 0.7.3
      放入ProblyStolen_friendwine.dll文件直接启动游戏可能报错
      如果报错，请下载MenlonLoader0.7.3并且删除或重命名游戏自带的 0Harmony.dll 文件为 0Harmony.dll.bak  。因为游戏本地所带的Harmony版本较低，删除或者重命名会使游戏启动时使用你下载的新版Hanrmony
      该文件存放在SteamLibrary\steamapps\common\Probably Stolen\Probably Stolen_Data\Managed文件夹下面
      
此文件夹路径如何寻找：
      打开steam库，右键深空当铺->属性->已安装文件->浏览     可打开游戏根目录，即SteamLibrary\steamapps\common\Probably Stolen
